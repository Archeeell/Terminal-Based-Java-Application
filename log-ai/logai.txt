Aku mau diskusi sama kamu terlebih dahulu, kenapa membandingkan
string tidak bisa menggunakan ==? tapi di bahasa pemrograman
lain bisa?
----------------------------------------------------------------
CLAUDE:
Jawabannya ada pada bagaimana Java menyimpan data di memori.

KONSEP DASAR: Stack vs Heap
- Stack -> menyimpan variabel primitif (int, double, boolean, dll)
- Heap  -> menyimpan objek, termasuk String

Contoh:
  int a = 5; int b = 5;
  a == b  --> TRUE (nilai disimpan langsung di Stack)

  String x = new String("express");
  String y = new String("express");
  x == y  --> FALSE (membandingkan alamat memori di Heap, bukan isi)

Ilustrasi memori:
  STACK               HEAP
  -----               ----
  x  ------------>  [0x001] "express"
  y  ------------>  [0x002] "express"
  x == y berarti: apakah 0x001 == 0x002? --> FALSE!

KENAPA DI BAHASA LAIN BISA?
  Python     : == membandingkan nilai/isi secara default
  JavaScript : == membandingkan nilai untuk primitive string
  C#         : == di-override khusus untuk String
  Java       : == selalu membandingkan alamat memori (referensi)

PENGECUALIAN - String Pool di Java:
  String a = "express";          // dari String Pool
  String b = "express";          // dari String Pool yang sama
  a == b --> TRUE (kebetulan sama karena String Pool)

  String a = "express";
  String b = new String("express"); // objek baru di Heap
  a == b --> FALSE

  Inilah yang membuat bug ini sangat berbahaya - tidak konsisten!

KESIMPULAN:
  ==        -> membandingkan ALAMAT MEMORI (referensi)
  .equals() -> membandingkan ISI/NILAI String

USER:
Berarti dalam java ketika kita membandingkan suatu nilai kita
menggunakan .equals()?
----------------------------------------------------------------
CLAUDE:
Tidak selalu! Tergantung pada tipe datanya.

ATURAN PERBANDINGAN DI JAVA:

1. Tipe Primitif -> Gunakan ==
   int, double, float, long, short, byte, char, boolean
   Contoh:
     int a = 10; int b = 10;
     a == b --> TRUE

2. Tipe Objek (Reference Type) -> Gunakan .equals()
   String, Array, ArrayList, class buatan sendiri
   Contoh:
     String a = new String("laundry");
     String b = new String("laundry");
     a == b       --> FALSE (beda alamat memori)
     a.equals(b)  --> TRUE  (sama isinya)

3. Objek Buatan Sendiri -> .equals() perlu di-override
   Contoh:
     Pelanggan p1 = new Pelanggan("Budi", "08123", "Bali");
     Pelanggan p2 = new Pelanggan("Budi", "08123", "Bali");
     p1 == p2       --> FALSE
     p1.equals(p2)  --> FALSE juga! (kecuali di-override)

   Untuk bisa TRUE, harus override method equals():
     @Override
     public boolean equals(Object obj) {
         if (this == obj) return true;
         if (!(obj instanceof Pelanggan)) return false;
         Pelanggan other = (Pelanggan) obj;
         return this.nama.equals(other.nama);
     }

RINGKASAN:
  Tipe Primitif         -> gunakan ==
  Tipe Objek/Reference  -> gunakan .equals()
  Objek buatan sendiri  -> .equals() perlu di-override

public class Pesanan {
    private String idPesanan;
    private Pelanggan pelanggan;
    private JenisLayanan jenisLayanan;  // pakai enum
    private double beratCucian;         // typo diperbaiki
    private String status;
    private double totalBiaya;

    public Pesanan(String idPesanan, Pelanggan pelanggan,
                   JenisLayanan jenisLayanan, double beratCucian) {
        this.idPesanan = idPesanan;
        this.pelanggan = pelanggan;
        this.jenisLayanan = jenisLayanan;
        this.beratCucian = beratCucian;
        this.status = "masuk";
        hitungBiaya();
    }

    private void hitungBiaya() {  // private
        totalBiaya = beratCucian * jenisLayanan.getHarga();
    }

    public String getIdPesanan() { return idPesanan; }
    public String getStatus() { return status; }
    public double getTotalBiaya() { return totalBiaya; }
    public double getBeratCucian() { return beratCucian; }
    public JenisLayanan getJenisLayanan() { return jenisLayanan; }
    public Pelanggan getPelanggan() { return pelanggan; }
    public void setStatus(String status) { this.status = status; }

    public void tampilPesanan() {
        System.out.println("=== Detail Pesanan ===");
        System.out.println("ID Pesanan   : " + idPesanan);
        System.out.println("Pelanggan    : " + pelanggan.getNama());
        System.out.println("Telepon      : " + pelanggan.getNomorTelepon());
        System.out.println("Jenis        : " + jenisLayanan.getLabel());
        System.out.println("Berat        : " + beratCucian + " kg");

--- KasirLaundry.java (Direvisi) ---
import java.util.ArrayList;

public class KasirLaundry {
    private ArrayList<Pesanan> daftarPesanan = new ArrayList<>();
    private int counterID = 1;

    public void tambahPesanan(Pelanggan pelanggan,
                               JenisLayanan jenisLayanan, double berat) {
        String id = "LDR-" + counterID;
        counterID++;
        Pesanan p = new Pesanan(id, pelanggan, jenisLayanan, berat);
        daftarPesanan.add(p);
        System.out.println("Pesanan berhasil ditambahkan! ID: " + id);
    }

    public void updateStatus(String idPesanan, String statusBaru) {
        boolean ketemu = false;
        for (Pesanan p : daftarPesanan) {
            if (p.getIdPesanan().equals(idPesanan)) {  // .equals()
                p.setStatus(statusBaru);
                System.out.println("Status berhasil diubah!");
                ketemu = true;
            }
        }
        if (!ketemu) {
            System.out.println("ID Pesanan tidak ditemukan!");
        }
    }

    public void tampilSemuaPesanan() {
        if (daftarPesanan.isEmpty()) {
            System.out.println("Belum ada pesanan.");
            return;
        }
        for (Pesanan p : daftarPesanan) {
            p.tampilPesanan();
            System.out.println("---------------------");
        }
    }

    public Pesanan cariPesanan(String idPesanan) {
        for (Pesanan p : daftarPesanan) {
            if (p.getIdPesanan().equals(idPesanan)) {  // .equals()
                return p;
            }
        }
        return null;
    }
}
